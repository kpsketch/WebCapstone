WebCapstone

WebCapstone is a Kids Learning Web App developed as a capstone project. The goal of this project is to create a simple and interactive website where children can learn basic topics such as ABC, Numbers, Colors, Shapes, and Animals.

This project is built using:

PHP

MySQL

HTML

The database name is webcapstone_db and it is set up using XAMPP. Currently, the project includes the basic folder structure, database setup, and connection testing.

Further development will include displaying topics, adding quiz functionality, and improving the user interface.
