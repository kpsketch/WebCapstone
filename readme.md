# Kids Learning Hub

Kids Learning Hub is an interactive educational website designed for children to learn through images, sounds, and quizzes. The project helps kids explore letters, numbers, colors, shapes, and animals in a fun and engaging way.

## Features

- Learn ABC letters with sounds and popup visuals
- Learn numbers with audio support
- Learn colors and shapes interactively
- Animal learning section with sounds and large popup images
- Interactive quiz system
- Correct and incorrect answer feedback
- Quiz score tracking
- User registration and login system
- Saved quiz progress and result history
- Responsive kid-friendly design
- Audio playback for better learning experience
