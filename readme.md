Kids Learning Web App
Project Description

This project is a simple interactive learning website for kids. It includes different sections such as ABC, Numbers, Colors, Shapes, and Animals. Children can click on letters, numbers, or images to see related pictures and hear sounds.

There is also a small quiz section where kids can answer questions and see their score at the end.

Technologies Used

HTML

CSS

JavaScript

Features

Interactive learning sections

Clickable images with sound

Simple quiz with score display

Responsive design for desktop and mobile

How to Run

Download or clone the project.

Open the folder in VS Code.

Open index.html in a browser or use Live Server.

Purpose

This project was created as a Capstone project to practice front-end development and build an interactive website using HTML, CSS, and JavaScript.
